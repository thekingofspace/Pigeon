Changelog

What has changed, newest first. Nothing is tagged yet, so it all sits under Unreleased.

Unreleased

Breaking

  • On can no longer answer a Call. Move it to When.
  • Rooms on a guarded carrier refuse players who have not passed the guard.

Added

ChangeWhat to do
carrier:When(event, callback) sets the one responder for an event. What it returns answers a Call. Add a When for every event you call.
carrier:Revoke(targets) takes an approval back and clears the player from the carrier's rooms and staged tables. Use it to shut one player out. Re-join their rooms yourself.
Network.ReceiveChannel(channel, callback) watches a whole channel. Nothing, unless you use the transport directly.

Changed

ChangeWhat to do
Routing is by kind. Emit and the broadcasts reach On. Call and CallTo reach When. Split a handler that did both jobs in two.
Packet metadata travels as a buffer instead of separate strings, so a call costs 27 bytes of bookkeeping rather than 96. Nothing. Your arguments are unchanged. See Optimizations.
On is fire and forget. Many are allowed, each is spawned, and a return goes nowhere. Move anything that answered to When.
When replaces instead of appending. One per event. Register it in one place. A second one takes over silently.
When(event, nil) clears the responder and keeps the listeners. Use it to drop a responder you wrote inline.
Off(event, callback) removes a listener or the responder. Off(event) clears both. Pass the callback to take off just one.
An error in On is a normal Roblox error. An error in When warns and sends no answer. Watch for responder in the output. The caller sees a timeout.
A held packet replays by kind: requests to a When, the rest to an On. Register the When before clients call.
Reserved events follow the split. Ping, handshake and table request use When. Keep off the __pigeon_ names.
CreateRoom and JoinRoom raise ERR_NOT_APPROVED on a guarded carrier. One refusal adds nobody. Handshake first, then join.
A guard that throws now clears an approval the player had. Keep guards to judging and returning a boolean.

Fixed

ChangeWhat to do
A client leaving mid request no longer errors the server. Every send is checked and wrapped. Drop any pcall you added for this.
nil arguments survive in any position, both directions, replies included. Stop padding arguments. A nil inside a table is still a hole.
A staged table view follows its table being replaced by a patch or snapshot. You can hold a nested view again.
Unreliable packets arrive once, not twice. Nothing.
carrier:On does nothing on a dropped carrier. Nothing.
